# Web ↔ DISCIPLE FLOW contracts wiring

These are wired against `flow/contracts-v0` (PR #1). `/contracts` is used read-only.

## Files
- `web/lib/abi/*.ts`: typed `as const` ABIs (abitype-compatible, used by viem). They're generated by `node web/scripts/gen-abi.mjs` from `contracts/out` (`forge build`; `CONTRACTS_OUT` overrides the path).
- `web/lib/chains.ts`: per-chain addresses from env (`NEXT_PUBLIC_RH_*`, `NEXT_PUBLIC_ANVIL_*`, `NEXT_PUBLIC_CHAIN_ID`), with zero placeholders until deploy. `NEXT_PUBLIC_DIRECT_WALLET=1` turns on the dev-only direct-signing path.
- `web/lib/curveMath.ts`: off-chain mirror of `CurveMath` + fees, used for quotes and impact.
- `web/lib/protocol-viem.ts`: `ProtocolClient` implementation.
  - `launchCoin` → `Launchpad.launchCoin`. `quote = address(0)` means `defaultQuote` (STRATEGY), and Advanced mode passes a custom ERC-20. `QuoteRejected` and the other custom errors are mapped to friendly copy.
  - `buy` / `sell` → `BondingCurve.buy/sell`. `minOut` comes from the off-chain quote plus `slippageBps` (default 1%), and the deadline defaults to now + 120 s. After graduation it throws a clear TODO (no v4 router in the PR).
  - `getCurveState` reads mcap, % sold of supply, % progress to the 72% graduation point, the next tier, graduated, reserves and creator tax.
  - `impactPct` gives a pre-trade estimate from curve math.
- `web/lib/events.ts`: watches `Launched`, `LaunchTierContext` and `CreatorTransferred` on the Launchpad, plus `Buy`/`Sell`/`GraduatedToV4` per curve. Trades become a `Trade` event with `impactPct`, which goes to the engine (`window "disciple:event"` → `DiscipleSource`, used for bombs) and to the launchpad cards. The AI/WETH v3 demo is unchanged.
- Custody: by default trades go to `/api/execute/{trade,launch}` (platform executor, one approval at deposit, no per-trade signing). Those routes return **501** until FLOW ships a vault.

## Local anvil
`CONTRACTS_DIR=../contracts web/scripts/dev-anvil.sh` starts anvil, runs `Deploy.s.sol`, deploys a mock quote as `defaultQuote` and writes `web/.env.local`. It is **currently blocked by a hook-salt bug in Deploy.s.sol** (see gaps).

## Contract API gaps (for FLOW)
1. The **Trade event has no impact**: `Buy`/`Sell` emit amounts only (no price or tokensSold), so impact is reconstructed per log via a historical `tokensSold` read. Ask: add `tokensSoldAfter` / `priceAfter` / `impactBps`.
2. Event names differ from the brief: `Launched` (not `Launch`) and `GraduatedToV4` on the curve (not `Graduate`).
3. **No custody/vault**: `buyFor` is Launchpad-only, there's no `sellFor` or operator role, and there's no deposit contract. The "approve once, platform executes" flow can't be built on-chain yet.
4. **No v4 router/quoter** for post-graduation swaps (pool fee 0, hook 1%).
5. **`quotePriceUsd` is caller-supplied** with no oracle, and `0` silently defaults to $1. With STRATEGY at about $0.0018 that would misprice the curve. We need a price source or an on-chain oracle.
6. **No view quote functions** (`getAmountOut`), so the client mirrors CurveMath. Anti-snipe fees aren't modelled, so slippage has to cover the first 7 s (sniper tax 99% → 25% at 1s → 3% at 2s → 0 from 7s).
7. **Deploy.s.sol hook salt**: it's mined with `deployer` while the script deploys through the CREATE2 factory, which reverts with `HookAddressNotValid`. It also never sets `defaultQuote` or `quoteProbe`.
