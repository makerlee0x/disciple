# SEC-04 — ownership and privilege handover

Source baseline: `origin/main` **206b76d65d0826e6f2fa51f31205e3698e4138ac**. This is an execution checklist, not evidence of a live handover. Re-inventory the final merged source/ABI before signing. No transactions, addresses, Safe threshold or timelock delay are supplied here.

## Decisions and a real limitation (blocking)

- [ ] **OWNER DECISION:** Safe implementation/deployment, signer identities, threshold, signer custody/recovery and whether treasury custody is a separate Safe. Record verified addresses; no suggested numbers are facts.
- [ ] **OWNER DECISION:** timelock implementation, delay, proposer/executor/canceller/admin roles, who may change the delay, and final owner/admin destination for EVERY row below. No timelock implementation is deployed by this repository's default script.
- [ ] **OWNER DECISION:** emergency authority versus delay. The contracts below have a **single owner/admin**, not separate selector-scoped governance/pauser roles. There is **no protocol-wide `pause()` / `unpause()` API** in these sources. A Safe is not a timelock. If a timelock owns a contract, the Safe cannot bypass it for that contract's emergency setters. Either explicitly accept delayed emergency action or approve a separately audited role-separation change; do not claim the existing code provides both. This PR adds no such controller.
- [ ] Intended policy: delay fund redirection, wiring, allowlist additions, economic/oracle changes and ownership/admin changes. Restrict immediate Safe action to genuine containment (router kill / authorization removal / login revoke), only where the selected access architecture actually permits it. Restoring access and parameter changes should follow normal delayed governance. No broad arbitrary-call emergency bypass.

## Contract-by-contract inventory

`2-step` means [`Owned2Step`](../../contracts/src/utils/Owned2Step.sol): `owner()`, `pendingOwner()`, `transferOwnership(newOwner)` only nominates; **the nominee itself calls `acceptOwnership()`**. Zero nomination cancels; no `renounceOwnership`. `1-step` means the named transfer immediately changes the only authority, with no acceptance safety net. These distinctions must be reflected in the transaction plan.
