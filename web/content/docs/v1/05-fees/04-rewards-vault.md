# Rewards vault

The community rewards vault holds sniper tax from rockets that never graduated. To be shared out later (how is still being decided).

## What's in it

The sniper tax (on BOOSTs in a rocket's first 7 seconds) is held by the curve. If the rocket graduates, it goes into the locked liquidity instead. If it hasn't graduated 30 days after launch, anyone can send it here. Nothing else goes in. It's held in each rocket's base coin.

## How it's shared

Not decided yet. There are no on-chain distribution rules today. Payouts are made by the vault's owner, and every payout is recorded on-chain. [CONFIRM: FLOW + lee — distribution rules and timing before this page goes live.]

## Check it yourself

The vault is a public contract. Its lifetime total per asset and every payout are visible on-chain. See [Contract addresses](/docs/reference/contracts).
