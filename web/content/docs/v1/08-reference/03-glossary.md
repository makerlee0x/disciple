# Glossary

| Term | Meaning |
|---|---|
| **Altitude** | How high a rocket's value has climbed, shown as height. |
| **Altitude tiers** | The 18 named steps of that climb, from Launch Pad ($3,333) to Seventh Heaven ($7.77 billion). |
| **Anti-snipe fee** | The sniper tax on BOOSTs in a rocket's first 7 seconds: 99% at launch, 25% at 1s, 3% at 2s, 0 from 7s. |
| **ATOM** | The largest bomb: 50%+ price impact. |
| **Base** | The coin a rocket is paired with and priced in. STRATEGY by default. |
| **Board** | To buy into a rocket. |
| **Bomb** | A DUMP, shown on the chart. Its size is set by price impact. |
| **Bonding curve** | The starting price path. Each buy costs a little more than the last. The rocket trades on it until it reaches orbit. |
| **BOOST** | Buy. It lifts the rocket. |
| **BUNKER** | A bomb with 5–12% price impact. |
| **Call sign** | A rocket's ticker, like $HALO. Locked at launch. |
| **Creator** | The wallet that launched a rocket, or whoever it was handed to. Also "launcher". |
| **Creator tax** | An optional 0–7% fee set at launch, paid to the creator on curve trades only. |
| **Crew** | Everyone who holds a rocket. Everyone aboard flies together. |
| **CRUISE** | A bomb with 12–25% price impact. |
| **DUMP** | Sell. It drops a bomb. |
| **GRENADE** | A bomb with 2–5% price impact. |
| **Hold bonus** | A points multiplier, up to ×2.5, for holding a rocket in profit. Points only, never money. Coming soon: not yet applied to points. |
| **Identity** | A playstyle tag earned from your trades, like Believer or Trencher. |
| **King of the Hill** | A rocket's top boosters, ranked by total BOOST volume. |
| **Launch Pad** | The first named tier for how high a rocket's value has climbed ($3,333 to $12,000). Not the Launchpad page. |
| **Launchpad** | The home page that lists rockets. |
| **Launch mode** | PvE, PvP or Trench Warfare: a rocket's curve rules, picked at launch. Coming. |
| **LockedLP** | The contract that holds the liquidity after a rocket reaches orbit. It has no way to remove that liquidity. Liquidity is locked forever in the Uniswap v4 LP. |
| **Near orbit** | A Launchpad filter for rockets at least 60% of the way to orbit. |
| **Orbit** | The moment the starting price path is finished and the rocket moves to the open market on Uniswap. That is a value of $33,333 with 84% of the rocket bought. Liquidity is locked forever in the Uniswap v4 LP. |
| **NUKE** | A bomb with 25–50% price impact. |
| **Outer Space** | The named tier where a rocket reaches orbit, starting at $33,333. |
| **Pair** | A rocket and its base. |
| **Normie** | A pilot with no identity yet, and the prestige-0 label. |
| **Pilot** | A trader. |
| **Price impact** | How far one trade moves the price, in %. |
| **PUFF** | The smallest bomb: under 2% price impact. |
| **PvE / PvP** | Crew climbing together vs. every trader for themselves. Simulator difficulties and launch modes. |
| **Rarity** | Common, Rare, Epic, Legendary or Mythic. One scale for achievements and rocket parts. |
| **rHALO** | Off-chain points from achievements and play. Not a token. |
| **Rocket** | The thing you launch on DISCIPLE. |
| **Season rank** | Unranked to Divine, by rHALO points in the season. |
| **Simulator** | Free paper trading against bots. |
| **Thrust** | The visual force of a BOOST. |
| **Touch grass** | A calm flight view that shows only how high the rocket's value has climbed. |
| **Tramp** | A buy waiting below the price, on a rocket that has reached orbit. |
| **Trench Warfare** | The hardest mode: no guardrails. |
| **Trencher** | A fast in-and-out trader. |
| **USDG** | A dollar stablecoin on Robinhood Chain. mUSDG on testnet. |
| **Verified** | A checkmark the team grants after reviewing a rocket. |
| **Wall** | A sell waiting above the price, on a rocket that has reached orbit. |
