# Creator tax

Creator tax: optional, 0–7%, set at launch and fixed. Charged on top of the 1% fee on bonding-curve trades only. After graduation, trades pay just the 1% fee.

| | |
|---|---|
| Default | 0% |
| Range | 0–7% |
| Set | Once, at launch, under **Advanced** |
| Applies to | BOOSTs and DUMPs on the bonding curve |
| After graduation | None |
| Goes to | The creator |

## Example

A rocket with a 3% creator tax, on the curve. A $100 BOOST pays:

- $1.00 trade fee (split four ways, see [Trade fee](/docs/fees))
- $3.00 creator tax, to the creator

After graduation, the same BOOST pays only the $1.00 trade fee.

## Why it's fixed

Traders see the tax before they BOOST, and it can never go up. If you transfer your rocket, the tax rights go with it.
