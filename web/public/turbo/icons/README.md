# Small Turbo icons

Three 256×256 transparent PNGs in the same chrome style as the rocket and guns. These are files only. Nothing is wired up.

| File | What it is |
|---|---|
| `icon-ammo.png` | A stack of glowing energy cells, for a "+ammo" pickup when you already hold that gun. |
| `icon-map.png` | Meant as a folded holo-map for the MAP button. It reads more like a holo-tablet. |
| `icon-lock-on.png` | A targeting reticle, for dogfights. |
