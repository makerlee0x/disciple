# Map emblems

One emblem for each Turbo Royale drop zone. These are our own badges, not the coins' real logos. There is no text, no letters and no coin marks. These are files only. Nothing is wired up.

Each file is a transparent 512×512 PNG: a circular embossed chrome medallion with the motif in the centre, lit from the upper left.

| File | Map | Motif |
|---|---|---|
| `map-hype.png` | HYPE (aggressive) | A lightning bolt splitting a flame |
| `map-sol.png` | SOL (fast) | A sun with sharp speed lines |
| `map-eth.png` | ETH (steady) | A faceted crystal |
| `map-btc.png` | BTC (defensive, final circle) | A heavy vault door |

Contact sheet: `../../../../../docs/brand/turbo-skins/r2/emblems.webp`.
