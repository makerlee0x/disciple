# Map emblems

One emblem for each Turbo Royale drop zone. Each one is a chrome version of that token's own logo. There is no added text. These are files only. Nothing is wired up.

Each file is a transparent 512×512 PNG: a circular chrome medallion with the token's logo raised in polished metal, lit from the upper left. A thin ring and glow in the token's colour tell the maps apart. The logo outlines come from the official marks: the Bitcoin SVG, the Ethereum diamond's published geometry, Solana's three bars and the Hyperliquid mark lee sent.

| File | Map | Motif |
|---|---|---|
| `map-hype.png` | HYPE (aggressive) | Hyperliquid mark, mint glow |
| `map-sol.png` | SOL (fast) | Solana's three bars, teal-to-purple glow |
| `map-eth.png` | ETH (steady) | Ethereum diamond, cool silver glow |
| `map-btc.png` | BTC (defensive, final circle) | Bitcoin ₿, orange glow |
