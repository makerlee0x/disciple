# Air-drop pods

One pod per weapon, with that weapon visible through a clear window, plus a separate glow layer in the weapon's rarity colour.

Files are `airdrop-<weapon>.png` and `airdrop-<weapon>-glow.png`, each a transparent 1024×1024 PNG. See the README in the parent folder for names, tiers, and how the 3-slot swap works.

Nothing is wired up.
