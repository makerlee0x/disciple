# Storm wall, drop ship and trophy

Three props for Turbo Royale, sitting in this folder beside `chests/`, `weapons/` and `maps/`. These are files only. Nothing is wired up.

| File | Size | What it is |
|---|---|---|
| `storm-wall.png` | 2048×512 | A seamless horizontal band of pink energy storm, transparent at the top and bottom edges. It shows when a map closes. |
| `mothership.png` | 2048×1024 | A huge chrome carrier that pilots drop from, used on the drop screen. Side view, transparent. |
| `trophy-last-pilot.png` | 1024×1024 | The win-screen trophy: a chrome rocket on a champagne `#F3DFA8` pedestal with a laurel. Transparent. |

Contact sheet: `../../../../docs/brand/turbo-skins/r2/props.webp`.
